Exercício 1)

Primeiramente decidimos para cada tipo de filme listar o total de entradas de obras para adultos dos anos 80 sem recorrer a nenhum índice. 

+--------------+----------+
| titletype    | count(*) |
+--------------+----------+
| movie        |     3366 |
| short        |       71 |
| tvEpisode    |       42 |
| tvMiniSeries |        6 |
| tvMovie      |        2 |
| tvSeries     |        3 |
| tvSpecial    |        1 |
| video        |     2823 |
| videoGame    |       15 |
+--------------+----------+
9 rows in set (1,857 sec)


Com este comando conseguimos obter um tempo de realização equivalente a 1,857 segundos. Com este valor em mente decidimos adicionar índices para tentar otimizar o tempo de processamento do comando.

Criamos três índices diferentes ("titletype", "starYear" e "isAdult") e após a implementação destes mesmos foi testado novamente o tempo de processamento da tabela.


+--------------+----------+
| titletype    | count(*) |
+--------------+----------+
| movie        |     3366 |
| short        |       71 |
| tvEpisode    |       42 |
| tvMiniSeries |        6 |
| tvMovie      |        2 |
| tvSeries     |        3 |
| tvSpecial    |        1 |
| video        |     2823 |
| videoGame    |       15 |
+--------------+----------+
9 rows in set (0,724 sec)


Chegamos à conclusão que o melhor tempo foi adquirido após a implementação dos três índices (0,724 segundos).


-------------------------------------------------------Código------------------------------------------------------------

select titletype, count(*) from titlebasics where isAdult='1' and startyear>=1980 and startyear<=1989 group by titletype;

alter table titlebasics add index(titletype);
alter table titlebasics add index(startYear);
alter table titlebasics add index(isAdult);
select titletype, count(*) from titlebasics where isAdult='1' and startyear>=1980 and startyear<=1989 group by titletype;

drop index isAdult on titlebasics;
drop index startYear on titlebasics;
drop index titletype on titlebasics;

Exercício 2)

Tal como no exercício anterior, inicialmente, o código criado foi testado sem a criação de índices. 

+----------+
| count(*) |
+----------+
|      233 |
+----------+
1 row in set (22,453 sec)


Como é possível observar na tabela acima apresentada, o tempo de processamento foi bastante elevado (22,453 segundos).
Havia assim necessidade de uma criação de índices que minimizasse este tempo. Foram assim criados três novos índices: "primaryname", "characters" e "nconst" em ambas as tabelas.

+----------+
| count(*) |
+----------+
|      233 |
+----------+
1 row in set (0,047 sec)

Foi observada uma descida drástica no tempo de processamento após a implementação dos quatro índices (0,047 segundos).



------------------------------------------------------------------------------------------Código----------------------------------------------------------------------------------------------

select count(*) from namebasics, titleprincipals where namebasics.nconst = titleprincipals.nconst and namebasics.primaryname = "Woody Allen" and titleprincipals.characters = '[\'Himself\']';

alter table namebasics add index (nconst);
alter table titleprincipals add index (nconst);
alter table namebasics add index(primaryName);
alter table titleprincipals add index(characters);
select count(*) from namebasics, titleprincipals where namebasics.nconst = titleprincipals.nconst and namebasics.primaryname = "Woody Allen" and titleprincipals.characters = '[\'Himself\']';

drop index nconst on titleprincipals;
drop index nconst on namebasics;
drop index primaryName on namebasics;
drop index characters on titleprincipals;
